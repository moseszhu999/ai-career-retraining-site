Smart Contract Proof Registry

No backend database is required.

The frontend canonicalizes certificate, evidence, and score objects, computes hashes, then submits those hashes to ProofSkillCredentialRegistry. Verifiers read contract state directly.

Frontend hash pipeline

1
Canonical certificate JSON
credential type, holder, issuer, score band, validity.
2
Compute certificateHash
keccak256(canonical certificate JSON).
3
Compute evidenceHash
hash of Evidence Package summary and project outputs.
4
Compute scoreHash
hash of module scores, AgentScore, rubric version.
5
Wallet submits tx
registerCredentialProof(...) on contract.
registerCredentialProof(
  credentialId: 0xDATA_CREDENTIAL_ID_MOCK_001,
  holder: 0xLearnerMiaMock,
  credentialType: "AI_DATA_ANALYSIS_ASSISTANT",
  overallScore: 86,
  certificateHash: 0xCERT_HASH_DATA_MOCK_001,
  evidenceHash: 0xEVIDENCE_HASH_DATA_MOCK_001,
  scoreHash: 0xSCORE_HASH_DATA_MOCK_001,
  schemaHash: 0xSCHEMA_HASH_DATA_RUBRIC_V1,
  expiresAt: 1846195200
)

// Contract event

  credentialId,
  issuer,

  overallScore,
